# Blog Web Application

A full-stack blog platform where users can register, login, create, edit, and delete blog posts — built with modern web technologies.

---

## 🚀 Features

- ✍️ User authentication with secure login and signup  
- 📝 Create, read, update, and delete (CRUD) blog posts  
- 🛡️ JWT-based authorization for secure access  
- 👤 Automatically assigns authorship to logged-in users  
- 🖥️ Clean and responsive user interface  

---

## 🛠️ Tech Stack

**Frontend:**  
React.js, JavaScript, HTML5, CSS3  

**Backend:**  
Node.js, Express.js, REST API  

**Database:**  
MongoDB  

**Authentication:**  
JWT (JSON Web Tokens)
